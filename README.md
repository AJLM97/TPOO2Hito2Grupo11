# Sistema de Gestión "Epicentro Gourmet"

Proyecto desarrollado utilizando **Spring Boot** para la asignatura [Orientación a Objetos 2] - [2026 - Segundo Cuatrimestre]. 
Este software permite optimizar la administración de festivales temáticos anuales gestionando las unidades de venta (Food Trucks y Puestos Desarmables), el personal especializado de cada unidad y el rendimiento económico integral.
